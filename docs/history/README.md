# History

The original work orders and concept notes, in German, as they were written before each wave of
development (the Docker stack, the Garmin Connect import, the strap over Bluetooth, the Zepp cloud
draft). They are kept for the record and are not maintained; the English concept pages under
`docs/` (`docker-concept.md`, `strap-ble-concept.md`, `coach-concept.md`, …) and the README describe
what was built.
