Roadmap & getting involved

Where this is going

Everything marked shipped runs every morning on real hardware. The principle never changes: the database on your machine stays the single source of truth.

shipped

The full pipeline

Garmin watch over USB, the Helio Strap over Bluetooth without a phone, Gadgetbridge over ADB — every raw file archived immutably, parsed into one SQLite database, daily summaries merged across sources.

shipped

Ten years of history: the Garmin Connect export

Hand wristpull the account export zip and your whole history comes home — activities with their names, daily summaries, nights with sleep scores, VO2max and weight. Live data always wins; the export fills the past.

shipped

Dashboard, TUI, coach, workouts

The web dashboard for the phone (Today, trends up to ten years, activities, sleep, coach, workout editor), a ten-screen terminal UI in German and English, the auditable AI coach with three backends, and structured workouts pushed back to the watch.

shipped

Runs as a product already

One Docker image for everything, guided first-run setup, import on plug-in, a morning routine script, full-state backup and restore for moving machines, CI on Linux, macOS and Windows.

in progress

The wristpull Hub

The same stack on a small box you just plug in — hardware selection, first-boot experience and auto-updates. The beta list is open.

in progress

Smaller edges

Publishing a ready-made container image, scheduling workouts onto the watch calendar, more Gadgetbridge devices verified by their owners.

planned

Ask your data anything

An MCP server over the local database, so any AI assistant you already use can query your history — locally, with the same you-see-what-leaves principle.

planned

More of your health, same principle

Nutrition and body-scale data as additional sources, and the dashboard on a small home server for the whole household.

Get involved

Small tools keep big platforms honest

wristpull stays viable only if people run it, break it and report what they find. All of these help, in ascending order of effort:

Join the Hub beta list

One e-mail to bethechange@wristpull.de — every name is a vote that the Hub should exist.

Star, share, tell someone

Visibility is what lets an independent project survive. If you share the subscription fatigue, say so where the next person reads it.

Wish for a feature

GitHub issues are open — what would make you switch for good?

Run it on your devices

Another Garmin, a different band: every new device teaches the parsers something. The README shows how to report a file that parsed wrong.

Improve the coach's words

Coach prompts and the German translation are plain text. Better wording helps every user; the number check keeps the honesty.

Read the code

Python, tested, MIT. If you can audit it, audit it — a privacy claim is worth exactly as much as its most recent review.
